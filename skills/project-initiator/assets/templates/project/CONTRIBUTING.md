## Before you start

- Check open issues; for anything non-trivial, open one first to discuss.
- Security problems: see `SECURITY.md`, don't open a public issue.

## Setting up

Follow `docs/blueprint/SETUP.md`. Run {{verify_commands}} before opening a
pull request.

## Making a change

1. Branch from `main`; one logical change per pull request.
2. Add or update tests; keep the style of the surrounding code.
3. Update `CHANGELOG.md` under `[Unreleased]`.
4. Fill in the pull request template.
