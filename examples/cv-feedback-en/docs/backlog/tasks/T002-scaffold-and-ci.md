# T002 — Scaffold with create-next-app, test runner, first test, CI green

**Phase:** 0 | **Priority:** P0 | **Status:** ready | **Depends:** T001

## Goal

A current Next.js App Router project generated by the official tool, with
a test runner, one passing test and CI running lint, typecheck, test, build
and audit on every pull request.

## Steps

1. Branch `t002-scaffold`.
2. `npx create-next-app@latest --help` — confirm the flag names, then
   ([SETUP.md §3](../../blueprint/SETUP.md)):
   `npx create-next-app@latest app-tmp --typescript --eslint --app --src-dir --use-npm`
3. Move the generated files to the repository root; keep this repository's
   `README.md`, `docs/`, `AGENTS.md`, `CLAUDE.md`; merge the generated
   `.gitignore` entries into ours; delete `app-tmp/`.
4. Check the package names, then `npm install drizzle-orm better-auth ai`
   and `npm install -D drizzle-kit`.
5. Add the test runner (the owner's habit; otherwise Vitest) with a `test`
   script and one passing unit test; Playwright for the later smoke test.
6. Enable the commented steps in `.github/workflows/ci.yml` (SHAs already
   pinned). If `npm run build` needs env vars, give CI harmless placeholder
   values in the workflow `env`, never real secrets.
7. Open a PR; CI must be green.

## Acceptance criteria

- [ ] `npm run lint`, `npx tsc --noEmit`, `npm test`, `npm run build` pass
      locally and in CI
- [ ] `package-lock.json` committed
- [ ] No hand-written boilerplate that the generator would have produced
- [ ] CHANGELOG line added
