# Landscape — CV Feedback (working title)

*Purpose: commercial product · checked 2026-10-16 · quick depth (one
landscape search; both sources found are written by competitors, so treat
the table as indicative)*

## Verdict

**Build** — the owner wants to sell a product, so buying an existing CV
checker is not an option, and the product *is* the feedback experience.
The space is crowded, which makes speed and a clear differentiator more
important than stack polish: ship the waitlist in days, test whether people
come back for a second review.

## Success criteria

1. Landing page live by day 4, CV tool by day 14.
2. ≥ 500 waitlist signups within 4 weeks of the landing page going live.
3. ≥ 40 % of invited users run a review; ≥ 20 % of those run a second one
   within 14 days.
