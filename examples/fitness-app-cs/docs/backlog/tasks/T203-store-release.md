# T203 — Název, ochranná známka a vydání do obchodů

**Fáze:** 2 — Před spuštěním | **Priorita:** P0 | **Stav:** ready | **Závisí na:** T202

## Cíl

Vydat první verzi pod názvem, který nikomu nepatří.

## Kroky

1. Vybrat název; zkontrolovat ÚPV, EUIPO a obsazenost v obou obchodech.
2. Listingy obchodů (česky, slovensky), screenshoty, štítky soukromí,
   Data safety.
3. Projít kontrolní seznam vydání v `OPERATIONS.md`, tag `v1.0.0`.
4. Odeslat ke schválení (tvrdá brána), reagovat na připomínky.

## Kritéria přijetí

- [ ] Název zkontrolovaný a zapsaný v `LANDSCAPE.md`
- [ ] Aplikace schválená v App Store i Google Play
- [ ] CHANGELOG má verzi `1.0.0`
- [ ] `cd mobile && npm run lint && npm run typecheck && npm test` prochází
